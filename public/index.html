Hosting ASP.NET Core & Vercel Deployment

How Vercel Works with This Project

Vercel is optimized for frontend static sites, Next.js, and serverless Node.js functions. Because ASP.NET Core 9 is a compiled C# backend requiring a long-running .NET Kestrel server and SQL Server database, this repo includes a configured vercel.json and static showcase so your project deploys smoothly to Vercel without build errors.
